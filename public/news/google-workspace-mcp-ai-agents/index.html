Google opens Workspace to AI agents through MCP servers, and from February they must use them

On 24 November 2026, Google made its Workspace MCP servers and CLI generally available and set new rules for AI agents. What changed, the limits and dates, and what it means for growing businesses.

G
Groviadigi27 November 2026
3 min read
In short

On 24 November 2026, Google made its Workspace MCP servers and the Workspace CLI generally available, giving AI agents an official way into Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks. A new Workspace AI Tools Addendum says AI-driven tools must use these MCP servers rather than calling the Workspace REST APIs directly, enforced from 1 February 2027. The free Standard tier allows 5,000 MCP requests a day per project for each product, and paid Scaled tier billing starts on 1 April 2027.

Many businesses already let AI tools read their inbox, draft documents or update a shared sheet. Until now, each tool reached Google Workspace in its own way. On 24 November, Google set one official route for AI agents and a deadline for using it.

According to Google's Workspace Updates post, Google now hosts MCP servers for Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks, with Keep to follow. MCP (Model Context Protocol) is the common standard AI agents use to connect to apps. An official command-line tool, the Workspace CLI, is also generally available. Admins get new controls under Security, API Controls in the Admin console, including rules that make an agent ask a person before it acts, and audit logs of what agents did. The rollout reaches all domains over about two weeks.

The bigger change is in the rules. The new Workspace AI Tools Addendum says that when a tool is driven by an AI agent or AI model, it must go through Google's MCP servers instead of calling the REST APIs directly. Google's developer guidance says that from 1 February 2027, agents that keep calling the REST APIs will be held to free-tier limits whatever plan they are on. The free Standard tier allows 5,000 MCP requests a day per project for each product. A paid Scaled tier, with billing from 1 April 2027, is for heavier use. The addendum also bars agents from keeping user data beyond the task in hand or using it to train models. Data Phoenix covered the same limits and dates on 26 November.

What it means for growing businesses

If you use an AI assistant or agent that touches Gmail, Drive or Sheets, ask its maker one question before February: does it use Google's MCP servers yet? Tools that do not may slow down or hit limits after 1 February 2027. For most small teams, 5,000 requests a day per product is plenty, but an agent that sorts every incoming email or rewrites large sheets could reach it. The new admin controls are worth switching on whatever you use, especially the setting that makes agents ask before they send or delete anything.

Two things are not yet clear. Google's own pages differ slightly on whether the CLI counts alongside MCP and on how MCP billing works on the paid tier. And the rule is written for AI-driven tools, so ordinary scripts that move data on a schedule appear to sit outside it, though Google has not spelled that out. We would wait for Google's clarification before rebuilding anything that works today.
